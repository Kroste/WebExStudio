# Screenshots

Diese PNGs werden von der Haupt-`README.md` eingebunden. Lege echte Screenshots mit
**genau diesen Dateinamen** hier ab, dann erscheinen sie automatisch in der README.

| Datei | Was zeigen |
|---|---|
| `main-window.png` | Gesamtes Hauptfenster mit einem geladenen Flow (z. B. `projects/usv3/flow.json`). |
| `ui-overview.png` | Hauptfenster mit den sichtbaren Bereichen: Palette, Subnodes-Liste, Tabs, Canvas, Eigenschaften, Protokoll. |
| `example-1.png` | Minimaler Flow `function → goto → debug` auf dem Canvas. |
| `example-2.png` | `function → foreach → goto → debug`; foreach mit zwei Ausgängen (Element/fertig). |
| `example-3.png` | `if_then_else` mit then/else-Wires, die bei einem Folge-Node zusammenlaufen. |
| `example-4.png` | Main-Tab mit `call`-Node + geöffneter `login`-Subnode-Tab. |
| `example-5.png` | Laufender Flow am `debug`-Node angehalten, Toolbar zeigt **⏭ Weiter**, Protokoll zeigt Payload. |
| `settings.png` | Einstellungen-Dialog (Browser-Typ, Channel, Pfade, Headless). |

**Tipp zum Aufnehmen:** App starten (`dotnet run --project WebExStudio.UI`), den jeweiligen
Beispiel-Flow aus der README laden bzw. nachbauen, Fenster bildschirmfüllend, dann
mit dem System-Screenshot-Tool aufnehmen und als PNG hier speichern.
